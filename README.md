ВЫВОД

В результате данной работы была реализована СУБД на языке C++, поддерживающая шесть абстрактных структур данных: 

массив;
односвязный список;
двусвязный список;
стек;
очередь;
Full Binary Tree.

Для каждой структуры реализован базовый набор операций: 
добавление;
удаление;
чтение;
поиск.

Причём для списков - по четыре способа вставки и удаления (в голову, в хвост, до и после заданного элемента). 
Разработан интерфейс командной строки с единым стилем команд (первая буква - тип структуры) и поддержкой сохранения и загрузки состояния базы в файл. 
Для дерева вместо операции удаления, нарушающей свойство полноты, реализована проверка на Full Binary Tree.
Проведён анализ сложности операций с позиции BigO-нотации и описаны достоинства, недостатки и области применения каждой структуры. 
Программа стабильно работает на различных исходных данных, корректно сохраняет и восстанавливает состояние между запусками.
